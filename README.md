# Chocolate Cake Recipe

A simple HTML and CSS recipe page for a chocolate cake.

## Project Description

This project was created as part of Git and GitHub workflow practice. It demonstrates the use of branches, commits, pull requests, issues, and project management.

## Technologies

- HTML5
- CSS3
- Git
- GitHub

## Features

- Chocolate cake recipe
- Ingredients list
- Preparation steps
- Styled recipe layout
- Semantic HTML structure

## How to Run

Open `index.html` in a web browser.
